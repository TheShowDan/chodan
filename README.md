# chodan · Notebooks del canal TheShowDan

Aquí están los notebooks y archivos de los videos del canal de YouTube [TheShowDan](https://www.youtube.com/@TheShowDan): Python para químicos, ingenieros y científicos, explicado desde cero.

Cada video tiene su carpeta con el notebook, los datos y las figuras que usa, y un README con el enlace al video. Abre el notebook en Jupyter y ejecuta las celdas mientras lo ves.

## Cómo usar los notebooks

Descarga el repositorio con el botón verde **Code → Download ZIP**, o clónalo:

```bash
git clone https://github.com/TheShowDan/chodan.git
cd chodan
pip install -r requirements.txt
jupyter lab
```

Sin instalar nada: en [Google Colab](https://colab.research.google.com) ve a **Archivo → Abrir cuaderno → GitHub**, escribe `TheShowDan/chodan` y elige el notebook. Si el notebook lee un archivo de datos o una figura, súbelos a Colab con el panel de archivos.
