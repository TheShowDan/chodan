# chodan · notebooks del canal TheShowDan

Aquí están los notebooks y archivos de los videos del canal de YouTube [TheShowDan](https://www.youtube.com/@TheShowDan): Python para químicos, ingenieros y científicos, explicado desde cero.

Cada video tiene su carpeta. Abre el notebook en Jupyter y ejecuta las celdas mientras ves el video.

## Cómo usar los notebooks

Descarga el repositorio con el botón verde **Code → Download ZIP**, o clónalo:

```bash
git clone https://github.com/TheShowDan/chodan.git
cd chodan
pip install -r requirements.txt
jupyter lab
```

Sin instalar nada: en [Google Colab](https://colab.research.google.com) ve a **Archivo → Abrir cuaderno → GitHub**, escribe `TheShowDan/chodan` y elige el notebook.

## Ejercicios

Los notebooks traen ejercicios con ejemplos de química: conversión de número de onda en espectroscopía IR, filtrado de pesos moleculares con máscaras. La solución está en las celdas que siguen a cada enunciado.
